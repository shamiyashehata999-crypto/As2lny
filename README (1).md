# اسألني Fullstack

نسخة مجمعة وقابلة للتشغيل محلياً أو على خادم Node.js. تتضمن:
- Backend حقيقي بـ Express + SQLite + JWT
- حساب مالك واحد فقط بصلاحية admin عبر متغيرات البيئة
- تسجيل ودخول للمستخدمين
- طلب اعتماد خبير وحالات Pending → Verified → Active → Suspended
- ظهور الخبراء للمستخدمين فقط بعد التفعيل
- استشارات ومحادثات ورسائل وبلاغات
- لوحة مالك فيها إحصائيات وإدارة مستخدمين وخبراء
- API للذكاء الاصطناعي من الخادم فقط، بدون وضع المفتاح داخل التطبيق
- أقسام محتوى ومدفوعات وإعدادات جاهزة للتوسع

## التشغيل
1. Node.js 20+
2. انسخ `.env.example` إلى `.env`
3. ضع بيانات المالك ومفتاح الذكاء الاصطناعي إن رغبت
4. شغّل:
   ```bash
   npm install
   npm start
   ```
5. افتح `http://localhost:8080`

## ملاحظات مهمة
- هذه النسخة تستخدم SQLite لسهولة التشغيل المحلي.
- للنشر الحقيقي: فعّل HTTPS، وانقل قاعدة البيانات إلى PostgreSQL/MySQL، وأضف رفع مستندات حقيقي، تخزين ملفات، إشعارات، WebSocket للمحادثة الفورية، ومدفوعات عبر مزود حقيقي.
- مجلد `android/app-wrapper` هو غلاف Android WebView يمكن وصله بالواجهة نفسها بعد ضبط `window.ASALNI_API_BASE` أو تقديم الواجهة من نفس الدومين.
